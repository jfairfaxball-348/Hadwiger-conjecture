## Candidate comparison

### Candidate A — RL29 prepared one-coloring extension through z

Use exactly one A-list coloring of K-x and test whether its color on z can extend x in K-xz.

Merit: tightly bounded and directly addresses FL-032.

Audit concern: this is a tenth consecutive refinement of the same m=2 chain and lies inside the additional nested assumptions V(P)=T_2, x in K, and existence of z. Even a positive local conclusion would first be another edge/list incidence statement unless an independent sufficiency argument were supplied.

Decision: **not selected now**. Preserve as a later repair only if a future argument identifies a direct obligation-closing payoff.

### Candidate B — m=3, A=S terminal-core resource-family exchange gate

Return to the untouched RL13 m=3, A=S branch. Fix one actual joining edge for each of the three resource pairs. For each resource T_i, the two fixed joining edges incident with T_i determine one or two terminal vertices. Fix one spanning tree Q_i and the unique terminal-to-terminal path core R_i in Q_i (a singleton if the two terminals coincide).

Assess at most the three fixed candidates obtained by replacing T_i with R_i while leaving the other two resources unchanged. Nonemptiness, exteriority, disjointness, connectedness and the fixed three pairwise joining edges are built into the candidate. The only substantive gates are exact cyclic resource coverage of R_i and strict size R_i proper subset T_i.

If some R_i is a resource and strict, minimum total size is contradicted, excluding that retained m=3 configuration. If no side gives such a contradiction, stop with the exact first failed gate on each of the at most three fixed sides: either terminal-path saturation R_i=T_i or one explicit cyclic coverage defect of R_i.

Merit: changes the finite RL13 branch, uses a structural feature unique to m>=3 (two fixed joining obligations per side), has an independently sufficient contradiction if a strict resource core is certified, and has a hard bound of three candidates with no census.

Decision: **SELECTED**.
