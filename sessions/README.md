# Frozen RL sessions

Completed numbered research sessions are frozen here as `sessions/RL<N>/`.

This directory is historical provenance, not current authority.

A session directory should preserve the completed incoming generation, its promoted results and proof-state records, corrections/demotions, verification notes, closeout record, and the successor handover material needed to audit the transition.

Do not edit a frozen session merely to make later work look cleaner. Later corrections belong in later authoritative work and should point back to the affected historical claim.
