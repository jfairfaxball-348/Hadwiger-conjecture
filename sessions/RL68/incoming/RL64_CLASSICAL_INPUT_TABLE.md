## Answer to RL63's question

RL63 asked whether a separate Level-A gate for the extremal function is actually needed, and in what form. The answer is **no**: neither frontier proof consumes Mader's K7 extremal function (S2) or Gallai (S3). The only classical input both proofs consume is **Mader's 7-connectivity (S1)**, and the two papers cite it to different Mader papers. Dirac's lemma, also used by both, is already proved in the repository at k=7 (U4).
