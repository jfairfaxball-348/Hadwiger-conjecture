# Knowledge / lookup layer

This directory is reserved for non-authoritative indexes, catalogues, or lookup aids that make historical research easier to locate.

It contains no mathematical authority.

- `authoritative/` remains the sole incoming mathematical state.
- Missing or stale knowledge data never changes proof status.
- Absence from an index is never evidence that a historical result does not exist.
- Generated catalogue files, if added later, should not be hand-edited to simulate freshness.

At scaffold time no catalogue is generated.
